# Movie Recommendation System

A simple Python CLI movie recommendation system using a JSON movie database.

## Categories

- Action: 15 Bollywood movies
- Romance: 15 Bollywood movies
- Drama: 15 Bollywood movies
- Horror: 15 Bollywood movies

Total: **60 movies**

## Features

- CLI welcome screen
- Category selection
- Random selection of 5 movies
- Option to get another set of recommendations
- Movie data stored separately in JSON
- Simple and beginner-friendly project structure

## Run

```bash
python main.py
```
